# Background Agent System

The **Background Agent System** provides a framework for creating autonomous agents that execute tasks on a schedule. These agents are ideal for system monitoring, periodic reports, and data synchronization.

<Warning>
Background-agent docs are pending a deeper refresh. The current exported API is `BackgroundAgentManager`, and the active examples use that manager directly.
</Warning>

## BackgroundAgentManager

The `BackgroundAgentManager` is the primary manager for background agents. It handles creation, scheduling, status tracking, and shutdown.

Install the background extra before importing it:

```bash
pip install "omnicoreagent[background]"
```

```python
from omnicoreagent import BackgroundAgentManager

manager = BackgroundAgentManager()

await manager.start()
```

---

## Creating a Background Agent

To create a background agent, define the agent identity and model at the top level, then put the scheduled task fields inside `task_config`.

```python
agent_config = {
    "agent_id": "system_monitor",
    "system_instruction": "Monitor system resources and alert if usage is high.",
    "model_config": {"provider": "openai", "model": "gpt-4o-mini"},
    "task_config": {
        "query": "Check local CPU and Memory usage.",
        "interval": 300,  # Run every 5 minutes
        "max_retries": 2
    }
}

# Create and register the agent, then start the manager
await manager.create_agent(agent_config)
await manager.start()
```

## Management API

The manager exposes the small control surface needed to register, run, inspect, and stop scheduled agents:

| Method | Description |
|--------|-------------|
| `create_agent(config)` | Create and register a scheduled agent. |
| `start()` | Start the manager and scheduling loop. |
| `shutdown()` | Stop the manager and clean up agents. |
| `get_manager_status()` | Get a snapshot of manager state. |

---

## Observability

Background agents emit events just like standard agents. You can stream these events to monitor "self-flying" tasks in real-time.

```python
# Stream events for a background agent
status = await manager.get_manager_status()
print(status)
```

### Event Types
- `background_task_started`
- `background_task_completed`
- `background_task_error`
- `background_agent_status`

## Use Cases

### 1. 🗄️ Database Archival
Run an agent every 24 hours to find old records and archive them to S3 or a secondary database.

### 2. 🚨 Sytem Health Checks
Monitor disk space, memory usage, and service availability every 60 seconds.

### 3. 📰 Content Aggregator
An agent that fetches news from several sources once an hour, summarizes them, and saves the result to your blog or newsletter database.

## Best Practices

- **Timeout Management**: Keep `task_config.timeout` lower than `task_config.interval` unless overlapping runs are acceptable for your workload.
- **Resource Limits**: Set `request_limit` and `total_tokens_limit` in the agent config to prevent runaway costs if an agent gets stuck in a loop.
- **Persistent Storage**: Always use `redis` or `database` memory and event stores for background agents to ensure you don't lose progress if your main process restarts.
