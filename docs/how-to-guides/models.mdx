# Universal Model Support

All supported providers use LiteLLM and return the same native turn and
text-stream protocol:

---

## Supported Providers

```python
# OpenAI
model_config = {"provider": "openai", "model": "gpt-5.4"}

# Anthropic
model_config = {"provider": "anthropic", "model": "claude-sonnet-5"}

# Google Gemini
model_config = {"provider": "gemini", "model": "gemini-3.8-flash"}

# Groq (Ultra-fast)
model_config = {"provider": "groq", "model": "openai/gpt-oss-120b"}

# DeepSeek
model_config = {"provider": "deepseek", "model": "deepseek-chat"}

# Mistral AI
model_config = {"provider": "mistral", "model": "mistral-small-latest"}

# Azure OpenAI
model_config = {"provider": "azure", "model": "gpt-5.4"}

# OpenRouter (200+ models)
model_config = {"provider": "openrouter", "model": "anthropic/claude-sonnet-5"}

# Ollama (Local)
model_config = {"provider": "ollama", "model": "llama3.1:8b", "ollama_host": "http://localhost:11434"}
```

## GPT-5.6 Validation Model

The shared cookbook default is `gpt-5.6-luna`. Select `gpt-5.6-terra` explicitly
when you want that model instead:

```python
model_config = {"provider": "openai", "model": "gpt-5.6-luna", "max_tokens": 2500, "reasoning_effort": "none"}
```

For GPT-5.6 Luna, the provider requires `reasoning_effort="none"` when using
function tools on Chat Completions. Reasoning-enabled function calls require the
Responses API, which this runtime does not currently implement. The cookbook
sets `none` for its GPT-5.6 Luna/Terra configurations; explicit overrides survive.

`ModelConfig` and the shared cookbook leave sampling parameters unspecified by
default. Set `temperature` or `top_p` only when the selected model supports them.
Explicitly requested parameters are not silently dropped.

To run the opt-in validation against your API key:

```bash
PYTHONPATH=src python engineering/validation/live_native_runtime.py --require-litellm --env-file .env
```

Use `--scenario http_sse_live_delivery` to rerun one check and `--report /tmp/live.json`
to save its outcome.

The validation makes paid model requests using synthetic tasks and tools. It does
not print the API key. Override the model with `--model gpt-5.6-terra`.

## Thinking and Reasoning Models

Thinking models return data with each turn that must be sent back unchanged on
the next request, or a multi-step tool loop fails on its next step. OmniCoreAgent
keeps it with the turn and sends it back to the provider that issued it:

| Provider | Data kept and returned |
|----------|------------------------|
| `anthropic` (extended thinking) | Signed `thinking` and `redacted_thinking` blocks |
| `gemini` (thinking models) | The thought signature on each tool call |
| `openrouter` (Claude, Gemini, and others) | `reasoning_details`, returned at the top level of the assistant message |

This works with `run()` and `stream()`, across runs in the same session (the
data is kept in stored history), and after context compression. Other
providers receive exactly the fields they always did. Enable thinking with the
provider's usual setting, for example:

```python
model_config = {"provider": "anthropic", "model": "claude-sonnet-4-5", "reasoning_effort": "low"}
```

Memory privacy redaction never alters signatures or encrypted reasoning. If
the readable thinking text contains personal data that redaction must change,
the stored copy of that turn leaves the signed data out (and records
`continuation_dropped`) instead of storing a signature the provider would
reject; the running agent keeps its own copy.

Traces record that continuation data was present (counts and a digest on each
model call) and never store signatures or encrypted values; the thinking text
itself is recorded only with `capture="full"`.

## Environment Variables

```bash
# Hosted providers use this single OmniCoreAgent key
export LLM_API_KEY=your_api_key
```

OmniCoreAgent reads `LLM_API_KEY`. Select the provider through
`model_config["provider"]`; do not set provider-specific API-key variables in
OmniCoreAgent configuration.

## Provider Selection Guide

| Use Case | Recommended Provider |
|----------|----------------------|
| Complex reasoning | OpenAI (`gpt-5.6-terra`), Anthropic (`claude-sonnet-5`) |
| Fast inference | Groq (`openai/gpt-oss-120b`) |
| Cost-effective | DeepSeek (`deepseek-chat`) |
| Privacy-sensitive | Ollama (runs locally) |
| Multi-model access | OpenRouter (200+ models) |
| Enterprise / Azure | Azure OpenAI |

<Tip>
Switch providers based on your needs — use cheaper models (Groq, DeepSeek) for simple tasks, powerful models (GPT-5.6, Claude) for complex reasoning, and local models (Ollama) for privacy-sensitive applications.
</Tip>
