# The Body: Sensors & Actuators

In Module 1, we built the **Mind**—the ReAct loop that allows an agent to think.
But a mind without a body is just a philosopher in a box. It can't *do* anything.

Module 2 is about **The Body**.

## The Anatomy of an Autonomous Agent

We are moving away from the "Chatbot" paradigm where tools are just "functions you call."
In the **Autonomous Era (2026)**, we view tools as **Organs**:

1.  **Sensors (Input):** How the agent perceives the world *without* you telling it to.
    *   *Old Way:* User pastes a CSV file.
    *   *New Way:* Agent watches a Redis Stream, listens to a WebSocket, or polls an API.
2.  **Actuators (Output):** How the agent changes the world.
    *   *Old Way:* Agent prints text to the console.
    *   *New Way:* Agent signs a transaction, deploys a container, or sends a DM on Moltbook.
3.  **The Nervous System (MCP):** The standard protocol that connects these organs to the brain.

## Why "Tools" is the Wrong Word

When you think "Tool", you think of a hammer. You pick it up, use it, put it down.
When you think "Organ", it is **always on**.

*   Your heart doesn't stop beating when you sleep.
*   Your eyes don't stop seeing just because you aren't talking.

**OmniCoreAgent v1.0** treats integrations as live, persistent connections.

## What We Will Build

In this module, we will give your agent:
1.  **Hands:** We will connect to the **Model Context Protocol (MCP)** to give it standardized tools.
2.  **Eyes:** We will build a **Real-Time Observer** that watches a data stream.
3.  **Reflexes:** We will implement **Interrupt-ability**—so the agent can stop thinking if the environment changes.

Let's build the body.
