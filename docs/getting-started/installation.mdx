# Installation

## Prerequisites

Before installing OmniCoreAgent, ensure you have the following:

<Info>
**System Requirements:**
- **Python 3.12–3.14** (development and CI use Python 3.12)
- **LLM API key** from any supported provider (OpenAI, Anthropic, Google, etc.)
- **UV package manager** (recommended) or pip
</Info>

### Check Python Version

```bash
python --version
# Should show Python 3.12.0 or higher
```

### Install UV (Recommended)

UV is faster than pip and handles dependencies more reliably:

<Tabs>
  <Tab title="macOS/Linux">
    ```bash
    curl -LsSf https://astral.sh/uv/install.sh | sh
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
    ```
  </Tab>
  <Tab title="Python pip">
    ```bash
    pip install uv
    ```
  </Tab>
</Tabs>

## Installation Methods

<Tabs>
  <Tab title="UV (Recommended)">
    ```bash
    uv add omnicoreagent
    ```
  </Tab>
  <Tab title="pip">
    ```bash
    pip install omnicoreagent
    ```
  </Tab>
  <Tab title="From Source">
    For development or latest features:
    ```bash
    git clone https://github.com/omnirexflora-labs/omnicoreagent.git
    cd omnicoreagent
    uv sync
    ```
  </Tab>
</Tabs>

## Optional Production Extras

The base install stays focused on the core runtime and harness. Add heavier production integrations only when your agent uses them:

| Extra | Installs |
|-------|----------|
| `redis` | Redis memory and Redis-backed background task state |
| `postgres` | SQLAlchemy and PostgreSQL driver |
| `mongodb` | MongoDB async and sync drivers |
| `s3` | AWS S3 and Cloudflare R2 workspace storage |
| `serve` | OmniServe REST/SSE API server |
| `tokenizer` | tiktoken token counting |
| `otel` | OpenTelemetry OTLP/HTTP trace export |
| `langsmith` | LangSmith trace export through OTLP |
| `opik` | Comet Opik trace export through OTLP |
| `codemode` | Code mode: programs that call your tools, run in Monty 1.x |
| `docker` | Docker sandboxes for the `execute` tool |
| `e2b`, `modal`, `daytona`, `vercel` | Hosted sandboxes for the `execute` tool |
| `harbor` | Running this agent on Harbor and Terminal-Bench (`omnicoreagent harbor`) |
| `all` | Every extra above except `harbor` |

```bash
pip install "omnicoreagent[redis]"
pip install "omnicoreagent[serve]"
pip install "omnicoreagent[otel]"
pip install "omnicoreagent[all]"
```

With UV:

```bash
uv add "omnicoreagent[redis]"
```

## Verify Installation

After installation, check the version you got:

```bash
omnicoreagent --version
```

```text
omnicoreagent, version 0.4.0
```

These docs describe 0.4.0 and later. If the command is not found, `pip show
omnicoreagent` names the version you have; for 0.3.x, see *An older version was
installed* below.

## Troubleshooting

<AccordionGroup>
  <Accordion title="An older version was installed">
    OmniCoreAgent 0.4.0 needs Python 3.12 or later. On Python 3.10 or 3.11, pip does not
    fail: it quietly installs **0.3.9**, the last release that supported 3.11 —
    which cannot even build an agent (its package was published without one of
    its own modules, so `OmniCoreAgent(...)` raises `ModuleNotFoundError: No
    module named 'omnicoreagent.core.workspace'`).

    Check which Python you are installing into, and use 3.12 or later:

    ```bash
    python --version
    uv python install 3.12
    uv venv --python 3.12 && source .venv/bin/activate
    pip install omnicoreagent
    ```
  </Accordion>
  <Accordion title="Permission Denied">
    **Error**: Permission denied during installation

    **Solution**: Use user installation:
    ```bash
    pip install --user omnicoreagent
    ```
  </Accordion>
  <Accordion title="Missing Optional Backend">
    **Error**: `ImportError: Redis memory requires optional dependency 'redis'. Install it with: pip install 'omnicoreagent[redis]'`

    **Solution**: Install the extra the message names:
    ```bash
    pip install "omnicoreagent[redis]"
    ```

    Every extra is in the table above; `all` installs every one but `harbor`.
  </Accordion>
  <Accordion title="Getting Help">
    If you encounter issues:

    1. Search [existing issues](https://github.com/omnirexflora-labs/omnicoreagent/issues)
    2. Create a [new issue](https://github.com/omnirexflora-labs/omnicoreagent/issues/new) with:
       - Your operating system
       - Python version
       - Installation method used
       - Complete error message
  </Accordion>
</AccordionGroup>
