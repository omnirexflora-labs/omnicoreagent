# Tag catalog

Lexical census of literal tag names in producer/parser source. Includes examples and organizational tags, including example-only parameter names. Dynamic parameter tags are any `\w+` pair in `_parse_args`; XML in user/tool data is unbounded and is not an executable vocabulary.

All organizational base/extension tags below are consumed by the model as prompt prose. Runtime control tags and their parsers are mapped individually in the inventory closure table. Router/skill/observation result families have separate rows there.
