# AI Due Diligence Agent

A multi-agent investment-analysis workflow built with OmniCoreAgent. It turns a company name into a due-diligence package using specialized agents for research, market analysis, financial modeling, risk review, memo writing, report generation, and infographic generation.

This cookbook is designed to run in two modes:

- **Local demo mode**: no Tavily key required. The research stages use deterministic local tools so you can smoke-test the full orchestration path.
- **Live research mode**: set `TAVILY_API_KEY` and the research stages connect to Tavily through MCP.

## Agent Team

| Agent | Responsibility | Tools |
| :--- | :--- | :--- |
| Researcher | Gathers company basics, team, funding, product, and traction. | Tavily MCP or local demo research tools |
| Market Analyst | Analyzes TAM, SAM, competitors, positioning, and trends. | Tavily MCP or local demo market tools |
| Financial Modeller | Builds 5-year bear/base/bull revenue projections. | `generate_financial_chart` |
| Risk Specialist | Assesses market, execution, financial, and regulatory risk. | LLM analysis |
| Memo Writer | Synthesizes the prior outputs into an investment memo. | LLM synthesis |
| Report Generator | Publishes the memo as a professional HTML report. | `generate_html_report` |
| Infographic Generator | Creates a visual investment dashboard. | `generate_dashboard_infographic` |

## What This Demonstrates

- Multi-agent orchestration with explicit handoff between specialized agents.
- MCP as a live external tool source when available.
- Local tools registered beside MCP tools for deterministic smoke testing.
- Tool-generated artifacts: HTML reports, PNG charts, and PNG dashboards.
- Shared cookbook model configuration through `.env` and `cookbook/shared.py`.
- Safe artifact output outside the current working directory by default.

## Setup

Install OmniCoreAgent and the visualization dependencies:

```bash
pip install "omnicoreagent" matplotlib numpy pillow
```

Configure a model key in the repository `.env` or your shell:

```env
LLM_API_KEY=your_provider_key
OMNICOREAGENT_MODEL=gpt-5.4-mini
```

Optional live research:

```env
TAVILY_API_KEY=your_tavily_key
```

Live research uses Tavily through `npx mcp-remote`, so Node.js/npm must be available on your PATH when `TAVILY_API_KEY` is set.

Optional artifact output override:

```env
OMNICOREAGENT_DUE_DILIGENCE_OUTPUT_DIR=/tmp/omnicoreagent_due_diligence_outputs
```

If no output directory is set, generated files are written to your system temp directory under `omnicoreagent_due_diligence_outputs`.

## Usage

Run from this folder:

```bash
python due_diligence_workflow.py "Agno AI"
```

Run from the repository root:

```bash
python cookbook/advanced_agent/ai_due_diligence_agent/due_diligence_workflow.py "Agno AI"
```

Choose a provider or model explicitly:

```bash
python due_diligence_workflow.py "OpenAI" --provider openai --model gpt-5.4-mini
```

Quiet mode keeps the final summary but suppresses most progress output:

```bash
python due_diligence_workflow.py "DemoCo" --quiet
```

Full CLI reference:

```bash
python due_diligence_workflow.py --help
```

## Output

The workflow generates up to three artifact files:

1. `investment_report_[Company]_[Date].html`
2. `infographic_[Company]_[Date].png`
3. `revenue_chart_[Company]_[Date].png`

The terminal summary prints the exact output directory and the most recent generated files.

## Notes

Local demo mode is for validating the cookbook and showing the orchestration shape without depending on Tavily. When `TAVILY_API_KEY` is present, the researcher and market analyst use Tavily MCP for live search.
